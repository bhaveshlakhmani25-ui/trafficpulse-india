
## Role in TrafficPulse

OpenStreetMap will act as the base geographic and road-network layer.

## What it can provide

- Road network
- Road geometry
- Intersections
- Road classes
- Metro stations
- Bus stops
- Markets
- Hospitals
- Schools
- Other mapped POIs

## Real-time traffic?

❌ No.

OSM is not our live traffic source.

## How TrafficPulse uses it

OSM
→ road graph
→ geographic locations
→ POI context
→ routing foundation

Dynamic sources
→ traffic
→ incidents
→ crowd
→ weather

## Data access

Overpass API can be used to query selected OpenStreetMap
features by geographic area and tags.

## Important limitation

OSM data quality and completeness can vary by location.

## Licensing

OpenStreetMap data is released under the Open Database License (ODbL).
We must comply with its attribution/share-alike requirements where applicable.
